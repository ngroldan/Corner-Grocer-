# Corner-Grocer-

## Overview

The Corner Grocer project is a C++ application that analyzes grocery purchase data from a text file. The program reads each grocery item, counts how many times each item appears, and displays the results through a menu-driven interface.

## Features

- Search for the frequency of a specific grocery item.
- Display all grocery item frequencies.
- Generate a histogram using asterisks.
- Save purchase frequency data to a backup file.

## Technologies Used

- C++
- Standard Template Library (STL)
- File Input/Output
- Visual Studio / Codio

# Reflection

## Summarize the project and what problem it was solving.

This project was created to help the Corner Grocer analyze grocery purchase data automatically. Instead of manually counting items sold each day, the program reads data from a file and calculates how many times each item appears. It also provides a menu that allows users to search for specific items, display all purchase frequencies, and view a histogram of the results.

## What did you do particularly well?

I organized the program into separate functions, making the code easier to read and maintain. I also used a C++ map to efficiently store and retrieve grocery item frequencies.

## Where could you enhance your code?

I could improve the program by adding stronger input validation, better error handling for missing files, and making searches case-insensitive. These changes would make the program more user-friendly and reliable.

## Which pieces of the code did you find most challenging to write?

The most challenging part was reading the input file and storing the grocery items in a map while correctly counting their frequencies. I overcame this by reviewing course materials, testing my code frequently, and using C++ documentation.

## What skills from this project will be particularly transferable?

This project strengthened my skills in file handling, data structures, debugging, modular programming, and problem-solving. These skills will be useful in future C++ projects and software development work.

## How did you make this program maintainable, readable, and adaptable?

I used meaningful variable names, organized the code into logical functions, and followed consistent formatting. This makes the program easier to understand, maintain, and expand with additional features.
